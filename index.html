Analytics availability

The current backend exposes aggregate knowledge and conversation counts only. It does not yet record unanswered questions, response ratings, daily activity, or popular topics. Those metrics will need additional backend event tracking before they can be displayed accurately.

Settings

Security

  • Admin credentials are sent to your backend over HTTPS.
  • The admin session token is stored in this browser's session storage.
  • Never share the admin token or place Firebase credentials in this dashboard.
  • Sign out when using a shared device.
